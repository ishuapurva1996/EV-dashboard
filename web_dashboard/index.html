Source dates & how to read this dashboard

Station totals include available (E), planned (P), and temporarily unavailable (T) public stations. A station is a location; a port serves one vehicle. Registration counts include BEVs and PHEVs, exclude non-plug-in hybrids, and are maintained as a project seed. A seed refresh does not download a new registration year.

Opening history describes surviving stations in the current feed, not observed historical network size. Unknown opening dates and closed stations are absent. Latest population estimates are held constant across growth years. Puerto Rico may have missing EV registration values; missing values display as unavailable.

Airflow checks the station source daily at 02:30 UTC. A changed source triggers ingestion, dbt models and tests, a validated private export, and GitHub Pages publication. The computer and Docker services must remain running. A source check or site redeployment does not create newer source data.
